## Co živým Auth ověřeno není

V repozitáři není nalezen samostatný Firebase Auth test projekt ani konfigurace emulátoru. Starý test-modular podle README kombinuje **produkční Auth** s lokálním mockovaným RTDB; tím nesplňuje zadání živého scénáře pouze v testovacím prostředí. Nebyl proto použit pro skutečné přihlášení. Žádné produkční zápisy, účty ani Rules se nemění.

Konkrétní mezera: vydání a obnova skutečných tokenů, skutečný account lookup/email verification, mapování UID/profilu/role a Rules se dvěma oddělenými testovacími účty. K uzavření je potřeba autorizovaný samostatný Auth test projekt nebo emulátor s odpovídající konfigurací a účty A/B. Mockovaný příznak emailVerified není důkazem živého ověření.

V automatickém mock průchodu bylo při zadržení odpovědí zachyceno5 Auth refresh požadavků, v manuálním1. Není prokázán single-flight celé Auth vrstvy a tento test jej netvrdí. `autoCloudInit`, `firebaseRefreshAuth` a `cloudLoginFromModal` jsou přesně shodné s výchozím main; v105 se mění pouze dva guardy. Další diagnostika startup Auth souběhu patří samostatné hranici Auth A1 roadmapy, nikoli nevyžádané úpravě tohoto PR.
